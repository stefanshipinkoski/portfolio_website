Privacy Policy for Stefan Shipinkoski

Effective date: 7 September 2026

This is a private, limited-user productivity integration operated by Stefan Shipinkoski. Google user data is accessed only to complete tasks requested by an authorized user. It is not sold, used for advertising, or used to build advertising profiles.

1. Application and operator

This policy covers the private Google Workspace personal-assistant integration operated under the application name Stefan Shipinkoski. The integration connects the open-source Hermes Agent software with Google Workspace services and is intended only for Stefan and a limited number of users personally known to him.

2. Google data the application can access

After a user gives permission through Google's OAuth consent screen, the application may access:

  • Gmail: message metadata, message content, attachments, labels and drafts; and the ability to create, modify or send messages.
  • Google Calendar: calendars, events, event details and attendees; and the ability to create, update or delete events.
  • Google Drive: file names, metadata and file contents; and the ability to create, update, download, share or delete files when requested.
  • Google Docs and Sheets: document and spreadsheet content; and the ability to create or update that content when requested.
  • Google Contacts: names, email addresses and phone numbers on a read-only basis.
  • Basic account information: the authorized Google account's email address and OAuth authorization details.

3. How Google data is used

Google data is used solely to provide user-requested personal-assistant functions, such as finding an email, preparing a reply, checking a schedule, locating a Drive file, or updating a document after confirmation. Access is not used for advertising, credit decisions, surveillance, or unrelated profiling.

4. Storage and retention

OAuth credentials are stored in access-controlled files on Stefan's private computer. Information needed to complete a request may appear in local Hermes conversation history, logs, generated files or user-approved memory. Data is retained only for operational continuity, user-requested records, security, or troubleshooting, and can be deleted by the operator upon request. The public portfolio website does not receive or store Google OAuth tokens or Google Workspace content.

5. Processing and disclosure

When needed to complete a user's request, the minimum relevant content may be processed by the user's configured AI model provider. The current configured provider is Microsoft Azure AI Foundry. The integration does not sell Google user data, disclose it to data brokers, use it for advertising, or use it to train a general-purpose model. Data may also be disclosed when required by law or necessary to protect the user or the security of the system.

6. Security

The operator uses OAuth authorization instead of collecting Google passwords, restricts local credential-file access, limits access to authorized profiles, and seeks user confirmation before consequential external actions. No security method is perfect, but reasonable measures are used to protect credentials and user data.

7. User control, revocation and deletion

A user can revoke the application's Google access at any time from Google Account third-party connections. To request deletion of locally retained data associated with this integration, email stefanshipinkoski@gmail.com. Revoking access prevents new access but does not automatically remove local records already created at the user's request.

8. Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

9. Changes to this policy

This policy may be updated when the integration, its data practices, or applicable requirements change. The effective date at the top of this page identifies the current version.

10. Contact

For privacy questions or requests, contact Stefan Shipinkoski at stefanshipinkoski@gmail.com.
